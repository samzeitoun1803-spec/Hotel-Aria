# Vaultr V3 — DA « Arena »

Mêmes fonctionnalités que la V2 (`vaultr/v2`), direction artistique refaite pour être plus vivante et originale.

- **Ambiance** : nuit violette (`#0D0A1C`) avec des aurores de couleur qui bougent lentement et un léger grain.
- **Couleurs** : les actions en dégradé « feu » (rose `#FF2E7E` → orange `#FF9A1A`), l'argent en jaune électrique
  (`#FFD60A` → `#FF8A00`), le cyan `#3CE3FF` pour l'info, la menthe `#3DFFB0` pour le validé.
- **Typo** : Barlow Condensed en italique très gras pour les titres et les chiffres (esprit maillot de sport),
  Manrope pour le texte, JetBrains Mono pour les petites étiquettes.
- **Matière** : cartes en verre dépoli, bords lumineux, boutons qui brillent, dock flottant avec l'onglet actif en dégradé.
- **Mouvement** : halo arc-en-ciel qui tourne derrière le coffre, bandeau défilant façon stade sous le coffre,
  listes qui arrivent en cascade, point faible qui pulse, reflet qui passe sur les boutons principaux.
- Mode clair : version « jour » lavande et blanc, mêmes dégradés.

## Fichiers

- `app.html` : la page publiée ; `index.html` : la même page autonome (démo).
- `src/` : `base.css` (structure), `theme.css` (composants, recolorés depuis la V2 par `transform.py`),
  `theme3.css` (la DA Arena), `body.html` (l'appli).
