# Photos du site

Le site utilise **uniquement les photos du site officiel** [hotel-aria.fr](https://www.hotel-aria.fr/).
Tant qu'une photo manque, son emplacement s'affiche comme un aplat beige avec le nom du fichier attendu.

1. Lancer `./scripts/fetch-images.sh` : les photos officielles sont téléchargées dans `assets/images/_officiel/`.
2. Copier/renommer les photos choisies ici, avec ces noms :

| Fichier | Emplacement | Photo conseillée |
|---|---|---|
| `hero.jpg` | Plein écran d'ouverture | Façade ou vue la plus forte de l'hôtel (paysage) |
| `facade.jpg` | Section « L'hôtel », image verticale | Immeuble en pierre de 1890 |
| `square-mozart.jpg` | Section « L'hôtel », image horizontale | Square Mozart / vue depuis l'hôtel |
| `chambre-terrasse.jpg` | Chambres 01 | Chambre avec terrasse sur le square |
| `chambre-cour.jpg` | Chambres 02 | Chambre côté calme |
| `junior-suite.jpg` | Chambres 03 | Junior suite |
| `chambre-classique.jpg` | Chambres 04 + survol « Confort » | Chambre double |
| `chambre-accessible.jpg` | Chambres 05 | Chambre PMR ou salle de bains |
| `ambiance.jpg` | Image qui s'agrandit au scroll | Couloir, détail, lumière (paysage) |
| `petit-dejeuner.jpg` | Petit‑déjeuner (sticky) + survol | Salle ou buffet du petit‑déjeuner |
| `bibliotheque.jpg` | Bibliothèque + survol | Coin bibliothèque / salon |
| `reception.jpg` | Réception + survol | Hall / réception |
| `contact.jpg` | Fond de la section réservation | Façade de nuit ou entrée (paysage) |

Format conseillé : JPG, 2000 px de large max, ~300 Ko.
